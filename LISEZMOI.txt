Mypbp - projet Android (Capacitor)

OPTION A - compiler avec GitHub (rien a installer)
1. Creer un depot GitHub prive vide, puis y envoyer tout le contenu de ce dossier
   (dossier cache .github inclus) : git init && git add -A && git commit -m init
   && git remote add origin <url> && git push -u origin main
2. Onglet Actions > "Build APK" > attendre ~5 min > telecharger l'artefact "mypbp-apk"
3. Dezipper, copier app-debug.apk sur le telephone, l'ouvrir (autoriser "sources inconnues").

OPTION B - Android Studio
Ouvrir le dossier android/ dans Android Studio > Build > Build APK(s).

Apres modification de www/index.html : npm ci && npx cap sync android
